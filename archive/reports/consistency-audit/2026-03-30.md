## 详细发现

### 发现 1: api-design.md MenuItem 缺失 F11/F12 全部字段 🔁×4
- **严重度**: 🔴 矛盾
- **涉及文档**: api-design.md §5.1 MenuItemSchema vs shared/types.ts MenuItem
- **具体内容**: api-design.md §5.1 MenuItemSchema 只有基础字段，**完全缺失** DEC-037/DEC-050 引入的 6 个字段：`brief`, `briefDetail`, `allergens: AllergenTag[]`, `dietaryFlags: DietaryFlag[]`, `spiceLevel: number`, `calories: number | null`。shared/types.ts 和 menuAnalysis.ts Prompt v9 已完整包含。
- **风险**: 新 Agent 参考 api-design.md 生成的代码会丢失这些字段
- **建议修复**: 在 §5.1 MenuItemSchema 中补齐 6 个字段 + AllergenTag/DietaryFlag 类型定义

### 发现 2: api-design.md MealPlan 接口严重过时 🔁×4
- **严重度**: 🔴 矛盾
- **涉及文档**: api-design.md Chat输出格式 vs shared/types.ts MealPlan
- **具体内容**:
  - api-design.md: `pairingNote?: string` → types.ts: `rationale: string`
  - api-design.md 缺失: `version: number`, `currency: string`, `diners: number`
  - api-design.md: `totalEstimate` 是 optional → types.ts 是 required
  - agentChat.ts Prompt 与 types.ts 一致
- **建议修复**: 用 types.ts 的 MealPlan/MealPlanItem/MealPlanCourse 覆盖 api-design.md

### 发现 3: Analyze 超时值三方矛盾 🔁×4
- **严重度**: 🔴 矛盾
- **涉及文档**: api-design.md §1.5 vs shared/types.ts TIMEOUTS
- **具体内容**:
  - api-design.md §1.5: 前端 65s / Worker 35s
  - shared/types.ts: `ANALYZE_CLIENT: 75_000` / `ANALYZE_WORKER: 62_000`
  - 文档和代码应对齐到同一套数值
- **建议修复**: api-design.md §1.5 更新为与 types.ts 一致的值

### 发现 4: menuAnalysis.ts EU 过敏原编号表错误 🔁×4
- **严重度**: 🔴 矛盾
- **涉及文档**: worker/prompts/menuAnalysis.ts
- **具体内容**: Prompt 中的 EU 过敏原对照表：
  ```
  1=gluten 2=shellfish 3=fish 4=shellfish 5=peanut 6=dairy 7=egg 8=sesame 9=tree_nut 10=peanut 11=soy
  ```
  - 编号 2 和 4 都是 shellfish（EU 标准: 2=crustaceans, 4=fish）
  - 编号 5 和 10 都是 peanut（EU 标准: 5=peanut, 10=mustard）
  - 缺失 EU 标准中的 celery, mustard, sulphites, lupin, molluscs
- **影响**: 当菜单标注 EU 过敏原编号时，AI 转换结果可能错误，**影响食品安全**
- **建议修复**: 对照 EU Regulation (EU) No 1169/2011 Annex II 修正完整编号表

### 发现 5: api-design.md Chat Prompt 文档严重滞后 🔁×5
- **严重度**: 🟡 漂移
- **涉及文档**: api-design.md §4.2 vs worker/prompts/agentChat.ts
- **具体内容**: 文档 §4.2 仍描述为"所有输出为 JSON，不要 markdown" + "每次回复不超过 3 句话"。实际 agentChat.ts 为自然语言叙事 + 末尾 JSON 代码块 + 严格2句话限制 + MealPlan/OrderAction 输出 + 记忆系统三层注入 + 角色边界约束 + 首次回复必出方案规则。差距极大。
- **建议修复**: 用 agentChat.ts 实际 Prompt 结构重写 §4.2

### 发现 6: api-design.md 前端调用示例格式错误 🔁×4
